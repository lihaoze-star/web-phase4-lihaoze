01 / INTERACTION

拾光 SHIGUANG

把 25 分钟，
还给自己。

项目简介

拾光是一个极简的专注计时器：选择 25 或 5 分钟，按下开始，看着圆环一点点收紧。没有排行榜，没有声音，也没有“你必须专注”的弹窗。它只做一件事——把时间还给你。

为什么做它

我想练的不是“做一个计时器”，而是 DOM 更新、事件状态和界面反馈之间的关系。一个按钮在不同状态下要说什么、圆环应该怎么走、重置时如何不留下多余的定时器，这些细节比界面本身更难。

我做了什么

  1. 01

    两种时长，随时切换

    25 分钟与 5 分钟共用一套倒计时逻辑，切换时自动停下并重置，不会出现两个计时器同时跑。

  2. 02

    一个按钮，三种状态

    开始、暂停、继续。状态写在按钮文字和 aria-live 提示里，不依赖颜色单独传达。

  3. 03

    用圆环表达剩余时间

    SVG 圆环通过 stroke-dashoffset 跟随剩余时间，数字用等宽数字，读秒时不会左右跳动。

复盘 / WHAT I LEARNED

计时器让我第一次认真处理“状态”。看起来只是开始和暂停，实际上要同时照顾按钮文案、剩余时间、圆环进度和屏幕阅读器提示。

也让我养成了一个习惯：每次写 setInterval，都要先想清楚它什么时候被清掉。否则页面看起来正常，后台却可能藏着第二个、第三个数秒。

02 / THIS PAGE

这一页 THIS PAGE

用原生，写一个
能看的个人主页。

项目简介

这是你正在浏览的页面，也是我的第一份线上简历。它没有构建步骤，没有框架，只有三个 HTML 文件、一份 CSS 和两份 JavaScript。所有内容都可以在“查看源代码”里找到。

三个关键决定

  1. 01

    先结构，后装饰

    用 header、nav、main、section、article、footer 把页面搭起来，再加视觉。标题层级、跳转链接和键盘焦点都不是事后补的。

  2. 02

    375px 也是正式尺寸

    用 clamp() 控制字号、用 minmax(0, 1fr) 约束网格，再在手机宽度下重排导航和卡片。375px 下没有横向滚动条，也没有文字重叠。

  3. 03

    交互要有理由

    项目筛选、移动端菜单、计时器，都先保证没有 JavaScript 时内容仍然可读；再用原生 JS 增强。筛选不是 CSS :hover 的障眼法。

03 / ERROR PAGE

404 LOST & FOUND

迷路了，
也要好好说再见。

项目简介

错误页经常是用户唯一会看到的“意外页面”。与其交出一行冷冰冰的 Not Found，不如承认走丢、给出一条回家的路，再留一点品牌记忆。

我做了什么

整页只保留三个动作：解释发生了什么、给一个回首页的按钮、给一个去看项目的入口。巨大的 404 负责第一眼，橙色数字负责让人记住，剩下的交给清楚的文案。
